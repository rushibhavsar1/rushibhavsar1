# DeskPilot

AI sales desk for small businesses: every new lead gets a personal reply in under
2 minutes, written in the owner's voice, approved by the owner, then sent — with a
booking link and automatic follow-ups.

See `CLAUDE.md` for the product scope and rules, and `docs/BUILD_PROMPTS.md` for the build phases.

## Commands

| Command | What it does |
| --- | --- |
| `npm run dev` | start the web app |
| `npm run worker` | start the background worker |
| `npm run test` | run tests |
| `npm run typecheck` | run the TypeScript checker |
| `npm run db:migrate` | apply Supabase migrations |
